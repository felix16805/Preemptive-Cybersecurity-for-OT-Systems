# SafeCut Backend Configuration Guide

This document provides complete instructions for configuring and running the **SafeCut** backend services, including Supabase (PostgreSQL), Neo4j (Graph Database), Nodemailer (SMTP Alerts), and Upstash (Redis Rate Limiting).

---

## 1. Environment Variables Overview

Environment variables must be placed in a `.env.local` file at the root of the project. A template is provided in [.env.example](file:///d:/Ot_project/Preemptive-Cybersecurity-for-OT-Systems/.env.example).

### Required vs. Optional Services Matrix

| Service | Environment Variable | Role | Required? | Fallback Behavior if Missing |
| :--- | :--- | :--- | :--- | :--- |
| **Supabase** | `NEXT_PUBLIC_SUPABASE_URL` | Supabase API URL | **REQUIRED** | API routes fail with HTTP 503 Service Unavailable |
| **Supabase** | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Public client API Key | **REQUIRED** | Browser reads fail; console displays empty incident log |
| **Supabase** | `SUPABASE_SERVICE_ROLE_KEY` | Server-side elevated secret | **REQUIRED (Server)** | Falls back to anon key with security warning |
| **Neo4j** | `NEO4J_URI` | Bolt connection string | Optional | Falls back to static in-memory `OT_TOPOLOGY` |
| **Neo4j** | `NEO4J_USER` | Graph DB username | Optional | Required if `NEO4J_URI` is set |
| **Neo4j** | `NEO4J_PASSWORD` | Graph DB password | Optional | Required if `NEO4J_URI` is set |
| **SMTP Mailer** | `SMTP_HOST` | Mail server hostname | Optional | Email alerts skipped with console warning |
| **SMTP Mailer** | `SMTP_PORT` | Mail server port (587/465) | Optional | Defaults to 587 |
| **SMTP Mailer** | `SMTP_USER` | Mail sender username | Optional | Required if `SMTP_HOST` is set |
| **SMTP Mailer** | `SMTP_PASS` | Mail sender app password | Optional | Required if `SMTP_HOST` is set |
| **SMTP Mailer** | `ALERT_TO` | Recipient email address | Optional | Required if `SMTP_HOST` is set |
| **Upstash Redis**| `UPSTASH_REDIS_REST_URL` | Redis REST Endpoint URL | Optional | Webhook rate limiting bypassed |
| **Upstash Redis**| `UPSTASH_REDIS_REST_TOKEN`| Redis REST Auth Token | Optional | Webhook rate limiting bypassed |

## 2. Supabase Setup (Incident Logging & Audit Trail)

Supabase stores immutable incident records generated by SafeCut runs and adversary attacks.

### Step 2.1: Create Project
1. Log in to [Supabase](https://supabase.com) and create a new project.
2. In Project Settings > API:
   - Copy **Project URL** (`NEXT_PUBLIC_SUPABASE_URL`).
   - Copy **anon public key** (`NEXT_PUBLIC_SUPABASE_ANON_KEY`).
   - Copy **service_role secret key** (`SUPABASE_SERVICE_ROLE_KEY`).

### Step 2.2: Execute Database Schema Migration
Open the Supabase SQL Editor and run the following DDL:

```sql
-- Create the incidents table
CREATE TABLE IF NOT EXISTS public.incidents (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    session_id TEXT NOT NULL,
    threat_node TEXT NOT NULL,
    threat_ip TEXT,
    safecut_triggered BOOLEAN NOT NULL DEFAULT false,
    certificate_issued BOOLEAN NOT NULL DEFAULT false,
    edges_cut INT NOT NULL DEFAULT 0,
    safety_loops_preserved INT NOT NULL DEFAULT 0,
    total_safety_loops INT NOT NULL DEFAULT 0,
    log_messages TEXT[] NOT NULL DEFAULT '{}'::TEXT[]
);

-- Enable Row Level Security (RLS)
ALTER TABLE public.incidents ENABLE ROW LEVEL SECURITY;

-- Allow public read access to incidents (for the dashboard console)
CREATE POLICY "Allow public read access to incidents"
ON public.incidents
FOR SELECT
TO anon, authenticated
USING (true);

-- Allow service role full access (server backend uses this)
CREATE POLICY "Allow service role full access"
ON public.incidents
FOR ALL
TO service_role
USING (true)
WITH CHECK (true);
```

## 3. Neo4j Setup (Live OT Topology Persistence)

Neo4j stores and queries the active 12-node OT industrial control topology and isolation history.

### Option A: Local Docker Container
Run Neo4j locally using Docker:

```bash
docker run -d \
  --name safecut-neo4j \
  -p 7474:7474 -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/safecutpassword123 \
  neo4j:5.26.0
```

Set in `.env.local`:
```env
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=safecutpassword123
```

### Option B: Neo4j Aura (Cloud)
1. Create a free AuraDB instance at [Neo4j Aura](https://neo4j.com/cloud/aura/).
2. Copy the connection URI (e.g. `neo4j+s://xxxx.databases.neo4j.io`) and password into `.env.local`.

## 4. SMTP Alert Setup (Nodemailer)

To receive real-time email notifications on intrusions and containment:

### Gmail Setup:
1. Enable 2-Factor Authentication on your Google Account.
2. Navigate to **Google Account > Security > App Passwords**.
3. Generate a 16-character App Password (named e.g. "SafeCut").
4. Configure `.env.local`:
   ```env
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=587
   SMTP_USER=your_email@gmail.com
   SMTP_PASS=xxxx xxxx xxxx xxxx
   ALERT_TO=soc_team@domain.com
   ```

## 5. Upstash Redis Setup (Webhook Rate Limiting)

To prevent denial of service and alert flooding on `/api/webhooks/incident`:

1. Sign up at [Upstash](https://upstash.com) and create a Redis database.
2. In the database dashboard, find **REST API**.
3. Copy `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN` into `.env.local`.

## 6. Commands to Run and Validate the Backend

### Install Dependencies:
```bash
npm install
```

### Run TypeScript Type Check:
```bash
npx tsc --noEmit
```

### Run Production Build:
```bash
npm run build
```

### Start Development Server:
```bash
npm run dev
```
The server will start at `http://localhost:3000`.

### Health & Endpoint Testing via cURL:

#### Test Topology Endpoint:
```bash
curl -i http://localhost:3000/api/topology
```

#### Test SafeCut Isolation (Valid Payload):
```bash
curl -i -X POST http://localhost:3000/api/safecut \
  -H "Content-Type: application/json" \
  -d '{"sessionId": "TEST-001", "compromisedNode": "PLC_02", "threatIp": "192.168.10.102"}'
```

#### Test Quarantine Endpoint (Valid Payload):
```bash
curl -i -X POST http://localhost:3000/api/quarantine \
  -H "Content-Type: application/json" \
  -d '{"sessionId": "TEST-002", "compromisedNode": "PLC_02", "threatIp": "192.168.10.102"}'
```

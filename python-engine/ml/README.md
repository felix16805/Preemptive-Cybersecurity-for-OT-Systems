# SafeCut ML benchmark and synthetic coursework pipeline

This package supports a **ready-to-run synthetic dataset with 15,000 rows** and optional experiments on SWaT and TON_IoT. It does not replace SafeCut's current forbidden-register rule or safety-constrained isolation algorithm. The benchmark datasets have different features and must be trained/evaluated as separate experiments.

## Quick start: included 15,000-row synthetic dataset

The ZIP includes `datasets/synthetic_ot/ot_cybersecurity_synthetic_15000.csv`, generated by a deterministic statistical simulation of OT sensor telemetry, Modbus activity, network load, and four simulated attack families. It includes 15,000 rows, the binary target `label` (`0=simulated normal`, `1=simulated attack`), and descriptive `attack_type` metadata which the training pipeline intentionally excludes from features to prevent label leakage.

From PowerShell, either execute the root-level convenience script:

```powershell
powershell -ExecutionPolicy Bypass -File .\RUN_SYNTHETIC_ML.ps1
```

Or run manually:

```powershell
cd python-engine
py -m pip install -r requirements.txt
py -m ml.generate_synthetic_ot --rows 15000
py -m ml.train --dataset synthetic_ot --data "datasets/synthetic_ot/ot_cybersecurity_synthetic_15000.csv" --target-col label --max-rows 0
py -m ml.predict --input "datasets/synthetic_ot/ot_cybersecurity_synthetic_15000.csv" --limit 5
```

The generator refuses to create fewer than 10,000 rows. Use `--rows 20000` for 20,000 rows. A fixed default seed makes the dataset reproducible. The script writes a sidecar metadata JSON with row count, class counts, seed, attack-family counts and limitations.

## What models are compared?

- Logistic Regression
- Decision Tree
- Random Forest
- Extra Trees
- Linear SVM

The model-selection process uses validation macro-F1; final metrics are computed on a held-out test split. Reports include accuracy, attack precision/recall/F1, macro-F1, weighted-F1, false-positive and false-negative rates, ROC-AUC/PR-AUC where supported, training time, inference latency, confusion matrices and metric plots. Results are published to `public/ml-results/summary.json` for the Next.js `/ml-lab` page. The latest executed run's numeric summary is saved in `python-engine/reports/ml-results/RESULTS.md`. `python-engine/ml/predict.py` loads the saved model and applies it to matching CSV/JSON feature input; it explicitly warns that synthetic predictions are not real-world validation.

## Critical academic limitation

**This dataset is synthetic coursework data.** Its measurements and attacks are generated from statistical assumptions written for this project; they are not captured from a real industrial plant. High metrics show how the models perform within this synthetic simulation only. They do not establish performance against real attackers or production OT networks. Clearly disclose this fact in any report/presentation and do not describe these figures as real-world accuracy.

The benchmark feature schema also does not automatically match SafeCut's live CSTR/Modbus simulator. The trained offline models are not wired into automated isolation. Do not trigger cutting links based only on this classifier; retain rule-based fallback, session validation, safety constraints and independent certificate verification.

## Optional real dataset experiments

- **SWaT:** request access through iTrust/SUTD: <https://itrust.sutd.edu.sg/itrust-labs/datasets/>. Raw SWaT files are access-controlled and are not redistributed here.
- **TON_IoT:** use the official UNSW page: <https://research.unsw.edu.au/projects/toniot-datasets>. Follow the dataset's academic-use and citation terms.

Store those raw files under `datasets/swat/` or `datasets/ton_iot/` (or pass your own path). For example:

```powershell
py -m ml.train --dataset ton_iot --data "datasets/ton_iot/train_test_network.csv" --target-col label --max-rows 200000
py -m ml.train --dataset swat --data "datasets/swat/SWaT_Dataset_Attack_v0.xlsx" --target-col "Normal/Attack" --max-rows 200000
```

Prefer time-held-out or attack-scenario-held-out evaluation for final research reporting when dataset metadata supports it. Random row splits can overstate generalization for temporally correlated data.

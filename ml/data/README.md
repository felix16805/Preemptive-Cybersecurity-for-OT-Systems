# ToN_IoT Dataset Setup for SafeCut ML Pipeline

This guide explains how to obtain, place, and preprocess the ToN_IoT dataset for the SafeCut ML intrusion detection pipeline.

## Dataset Overview

**ToN_IoT** (Telemetry dataset of Network/IoT/OT) is a comprehensive cybersecurity dataset created by UNSW Canberra Cyber for IoT/OT network traffic analysis.

- **Source**: https://research.unsw.edu.au/projects/toniot-datasets
- **Format**: Multiple CSV files (network telemetry, system logs, etc.)
- **Labels**: Normal + multiple attack categories (DoS, DDoS, injection, ransomware, etc.)
- **Size**: ~1-2 GB uncompressed

## Directory Structure

```
ml/
├── data/
│   ├── raw/
│   │   └── ton_iot/          # Place raw CSV files here
│   └── processed/            # Generated by preprocessing
├── models/                   # Trained model artifacts
├── reports/                  # Evaluation reports
└── src/                      # ML source code
```

## Step-by-Step Setup

### 1. Download the Dataset

1. Visit: https://research.unsw.edu.au/projects/toniot-datasets
2. Download the **Network Dataset** (CSV format)
3. Extract the archive
4. You should have multiple CSV files like:
   - `ton_iot_network.csv`
   - `ton_iot_process.csv`
   - `ton_iot_memory.csv`
   - etc.

### 2. Place Raw Files

Copy all CSV files to `ml/data/raw/ton_iot/`:

```bash
mkdir -p ml/data/raw/ton_iot
cp /path/to/downloaded/*.csv ml/data/raw/ton_iot/
```

Expected structure:
```
ml/data/raw/ton_iot/
├── ton_iot_network.csv
├── ton_iot_process.csv
├── ton_iot_memory.csv
└── ...
```

### 3. Preprocess Data

Run the preprocessing pipeline:

```bash
cd ml
python -m ml.src.preprocess
```

This will:
- Load all CSV files from `ml/data/raw/ton_iot/`
- Inspect and report on columns
- Clean data (remove duplicates, handle missing values)
- Identify numeric and categorical features
- Create a scikit-learn preprocessing pipeline (ColumnTransformer)
- Perform temporal train/validation/test split (70/15/15)
- Save processed arrays as `.npy` files
- Save the preprocessor as `ml/models/preprocessor.joblib`
- Save feature names as `ml/models/feature_names.joblib`

**Output files in `ml/data/processed/`:**
- `X_train.npy`, `y_train.npy`
- `X_val.npy`, `y_val.npy`
- `X_test.npy`, `y_test.npy`

### 4. Train Model

Train the Random Forest classifier:

```bash
python -m ml.src.train
```

This will:
- Load preprocessed training data
- Train RandomForestClassifier (200 trees, max_depth=15)
- Evaluate on train/validation/test sets
- Print metrics: accuracy, precision, recall, F1, ROC-AUC, FNR, FPR
- Save model as `ml/models/intrusion_detector.joblib`
- Save training metrics to `ml/reports/training_metrics.json`
- Save feature importance (top 20)

**Expected metrics (baseline):**
- Accuracy: >95%
- Recall (Attack class): >90%
- FNR: <10%
- FPR: <5%

### 5. Evaluate Model

Run detailed evaluation:

```bash
python -m ml.src.evaluate
```

Outputs:
- `ml/reports/evaluation_report.json` - Detailed test metrics
- `ml/reports/classification_report.json` - Per-class metrics

### 6. Start ML API

Start the FastAPI inference service:

```bash
python -m uvicorn ml.api.main:app --reload --port 8000
```

Test endpoints:
```bash
# Health check
curl http://localhost:8000/health

# Get expected features
curl http://localhost:8000/features

# Make a prediction (with sample features)
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"features": {"duration": 1.5, "bytes": 1024, ...}}'
```

## Feature Engineering Notes

The ToN_IoT dataset contains these typical feature categories:

| Category | Example Features |
|----------|------------------|
| Temporal | `ts`, `duration`, `flow_duration` |
| Network | `src_ip`, `dst_ip`, `src_port`, `dst_port`, `proto` |
| Traffic | `bytes`, `packets`, `pkts_per_sec`, `bytes_per_sec` |
| TCP | `tcp_flags`, `ttl`, `window` |
| Service | `service`, `dns_query` |
| Labels | `label` (normal/attack), `attack_cat` (DoS, DDoS, etc.) |

**Preprocessing Pipeline:**
1. **Numeric features**: Median imputation + StandardScaler
2. **Categorical features**: Constant imputation ("unknown") + OneHotEncoder
3. **Label encoding**: LabelEncoder for attack categories

## Temporal Split Strategy

To prevent data leakage from temporal correlations:
- **Training**: First 70% of chronologically sorted data
- **Validation**: Next 15%
- **Test**: Final 15%

This ensures the model is evaluated on "future" traffic it hasn't seen.

## Troubleshooting

### No CSV files found
```
FileNotFoundError: No CSV files found in ml/data/raw/ton_iot
```
→ Ensure CSV files are in `ml/data/raw/ton_iot/`

### Memory issues during preprocessing
For large datasets, consider:
- Processing files in chunks
- Using `dask` instead of `pandas`
- Sampling for initial development

### Model not found
```
WARNING: Model not found at ml/models/intrusion_detector.joblib
```
→ Run `python -m ml.src.train` first

### Feature mismatch during prediction
```
Missing features: [...]
```
→ Ensure prediction request includes all features from `/features` endpoint

## Model Versioning

The model version is tracked in `ml/src/config.py`:
```python
MODEL_VERSION = "rf-toniot-v1"
```

This version is returned in all predictions for traceability.

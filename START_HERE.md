# SafeCut Complete Project — Start Here

## Live two-laptop demo

See **DEMO_STEPS.txt**. Short version:

1. Install Node.js on both laptops. Put both on the same phone hotspot.
2. Defender: double-click `START_DEFENDER.bat` (and `ALLOW_FIREWALL.bat` once).
3. Attacker: double-click `START_ATTACKER.bat`, type the IP shown on the console.
4. Type `demo` or `exploit` on the attacker.

## Run the web application only

1. Extract the full ZIP and install Node.js.
2. From the project root, run `npm install`, `npm run build`, then `npm start`.
3. Open `http://localhost:3000`.

## View included ML results

The ZIP includes a generated 15,000-row synthetic OT cybersecurity dataset, trained model artifacts and evaluation outputs. Start the Next.js app and open `http://localhost:3000/ml-lab` to view the stored results.

To regenerate/retrain everything on Windows PowerShell, run from the project root:

```powershell
powershell -ExecutionPolicy Bypass -File .\RUN_SYNTHETIC_ML.ps1
```

This trains Logistic Regression, Decision Tree, Random Forest, Extra Trees and Linear SVM, and regenerates JSON/CSV reports and plots.

## Important about scores

The bundled dataset is **synthetic** and was generated by a deterministic statistical simulation. Its evaluation scores are real measurements from the executed code, but they measure performance on that generated dataset only. They are not measurements from real industrial systems and must be described as synthetic coursework results in academic submissions. See `python-engine/ml/README.md` for dataset details and limitations.

Optional real datasets: SWaT requires access from iTrust/SUTD; TON_IoT is available under the stated dataset use/citation terms via UNSW. Their raw files are not bundled here.
